যেকোনো Bash বা PowerShell স্ক্রিপ্ট থেকে, অথবা PUT/POST রিকোয়েস্ট ব্যবহার করে আপনার নিজের অ্যাপ থেকে আপনার ফোনে নোটিফিকেশন পাঠান। যেমন, Linux এ curl অথবা Invoke-WebRequest ব্যবহার করে।

ntfy হলো https://ntfy.sh এর জন্য একটি Android ক্লায়েন্ট, ntfy.sh একটি বিনামূল্যের ও ওপেন সোর্স HTTP ভিত্তিক pub-sub সার্ভিস। এই অ্যাপ এ আপনি টপিকে সাবস্ক্রাইব করতে পারবেন এবং একটি সহজ HTTP API এর মাধ্যমে মেসেজ পাবলিশ পারবেন।

ব্যবহার:
* দীর্ঘ সময় ধরে চলা কোনো প্রক্রিয়া সম্পন্ন হলে নিজেকে অবহিত করুন
* ব্যাকআপ ব্যর্থ হলে আপনার ফোনে সংকেত পাঠান
* কেউ আপনার সার্ভারে লগ ইন করলে সতর্কবার্তা পাওয়া

উদাহরণ:

$ curl -d "আপনার ব্যাকআপ সম্পন্ন হয়েছে" ntfy.sh/mytopic
